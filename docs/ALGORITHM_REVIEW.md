# 訓練演算法審閱單

以下是研究與產品選項。AIAC 的正式公式以 `ALGORITHMS.md` 為準。

| 候選 | 研究與限制 | AIAC 可先驗證什麼 |
|---|---|---|
| R1 坡度修正配速 | 跑步耗能會隨坡度改變。跑步機實驗曲線受地面與戶外條件限制。[Minetti 等](https://pubmed.ncbi.nlm.nih.gov/12183501/) | 對有高程的跑步提供估算，先檢查平路與坡度誤差。 |
| R2 臨界速度 | 三分鐘全力測試能提供臨界速度相關估計。測試需要特定條件。[3 分鐘跑步測試研究](https://pubmed.ncbi.nlm.nih.gov/28816504/) | 先用使用者確認的成績做離線比較，保留手填值。 |
| R3 賽事預測 | 休閒跑者研究發現 Riegel 在半馬內校準較好，馬拉松常預測得過快。[Vickers 等](https://pubmed.ncbi.nlm.nih.gov/27570626/) | 顯示估計範圍和採用的成績，馬拉松另評估訓練量。 |
| R4 VO₂max | 手錶估計對照實驗室測量會有誤差，裝置及族群也會影響結果。[穿戴裝置驗證研究](https://pubmed.ncbi.nlm.nih.gov/31443347/) | 先顯示來源已有的估計與趨勢。 |
| R5 HRV 準備度 | 個別 HRV 引導有氧訓練在小型介入研究有正向結果。可比較個人趨勢和主觀回報。[Kiviniemi 等](https://pubmed.ncbi.nlm.nih.gov/17849143/) | 先審 D1 的提示情境。單日異常只列為觀察。 |
| R6 心率漂移 | 穩態運動中可能出現心血管漂移，氣溫、水分與強度會影響解讀。[生理實驗](https://pmc.ncbi.nlm.nih.gov/articles/PMC3761905/) | 用有心率、速度與時間串流的穩定跑步做前後段比較，先人工核對停等與爬坡。 |
| R7 單調度與壓力 | Foster 的研究用每日負荷波動描述訓練，結果適用性依樣本與負荷來源而異。[Foster](https://pubmed.ncbi.nlm.nih.gov/9662690/) | 可先顯示每週分布和連續訓練天數。 |
| R8 急慢性負荷比 | 研究方法與分母會改變結果，難從比值判斷傷害風險。[方法學評析](https://pubmed.ncbi.nlm.nih.gov/32502973/) | 保留可直接查閱的週負荷變化，候選延後。 |
| R9 心率區間 | 不同強度分布可用於比較，但區間界線和模型須先定義。[休閒跑者介入研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7739641/) | 優先清楚標示現有閾值的來源，再評估是否需要第二套模型。 |
| R10 跑步功率 | 不同裝置的功率結果會受量測方式與跑步條件影響。[裝置比較](https://pubmed.ncbi.nlm.nih.gov/32212955/) | 按裝置保留實測或估計來源，先比較同裝置的歷史。 |

先審三個案例即可。D1 比較「睡五小時但精神好」及「睡得夠但腿很痠」。B3 比較「同一堂間歇有臨界配速」和「只有主觀用力程度」。A1 比較「來源已提供負荷」及「只有運動時間」。試用中先顯示規則、來源與缺少的資料。
