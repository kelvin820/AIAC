不能跑步時，壺鈴可以怎麼用？

把全身壺鈴間歇當成當天維持活動的替代選項。它可以增加心肺需求，也會讓肌肉承受負荷。跑步與壺鈴仍分開記錄；相同的心跳或主觀用力程度，不代表兩堂課的刺激相同。

MCP · 連接你的資料工具

MCP 是資料／工具接口，本身不是 LLM 訂閱。支援 Streamable HTTP、Bearer 與標準 OAuth discovery／PKCE；授權資格取決於服務商。本版僅執行明確標記唯讀的工具。

只傳送你填寫的參數，不自動傳整段 Coaching 情境。工具服務可能有自己的計費。
