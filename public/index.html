資料保存在此電腦的 data/state.json。Live 模式會把個人設定、今日情境、週計畫、已確認記憶及最近 12 則對話送至你設定的 LLM 供應商。API Key 與 OAuth Token 保存在本機加密憑證庫，不回傳瀏覽器。

備份包含課表、活動摘要與軌跡、教練紀錄及個人設定。API Key、帳號授權和原始 FIT 檔需另外保管。

分析方式與額度

開啟頁面、編輯、匯入與同步不會觸發 LLM。沒有背景分析、自動重試或開發者 Key 回退。每日上限計算嘗試次數；失敗可能仍被供應商計費。輸入也會計費，次數與輸出上限並非金額保證。

MCP · 連接你的資料工具

MCP 是資料／工具接口，本身不是 LLM 訂閱。支援 Streamable HTTP、Bearer 與標準 OAuth discovery／PKCE；授權資格取決於服務商。本版僅執行明確標記唯讀的工具。

只傳送你填寫的參數，不自動傳整段 Coaching 情境。工具服務可能有自己的計費。
